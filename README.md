# quiz-content

Quiz files for the [quiz app](https://github.com/framegrabber/quiz), served via GitHub Pages at `https://framegrabber.github.io/quiz-content/`.

Open a quiz: `https://framegrabber.github.io/quiz/#src=<URL-encoded link to a quiz file>`.

The file format is documented in the app repo (`docs/quiz-format.md`).
